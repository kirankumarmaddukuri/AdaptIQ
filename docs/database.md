# Database Guide

## Overview

AdaptIQ uses **MongoDB Atlas** as its cloud database. The Spring Boot backend connects via Spring Data MongoDB, with a **write-through in-memory cache** (`DataStore.java`) for low-latency reads.

**Database Name:** `adaptiq`  
**Connection:** Configured via `MONGODB_URI` environment variable.

## DataStore — Hybrid Cache Architecture

`DataStore.java` acts as the single point of data access for all services.

### Startup Sequence

```
@PostConstruct init()
  ├── seedRolesAndCompetencies()   ← Only if roles collection is empty
  ├── seedDemoUser()               ← Ensures a demo user always exists
  └── loadFromMongoDB()            ← Populates in-memory maps from all collections
```

### Write-Through Pattern

```java
// Example: saving a user
public void saveUser(User user) {
    users.put(user.getId(), user);        // In-memory cache
    userRepository.save(user);            // MongoDB persistence
}
```

### Read Pattern

```java
// Fast in-memory reads
public User getUser(String userId) {
    return users.get(userId);
}
```

> All reads are served from memory (< 1ms). Writes go to both memory and MongoDB (< 10ms network round-trip to Atlas).

## Viewing Data in MongoDB Atlas

1. Go to [cloud.mongodb.com](https://cloud.mongodb.com)
2. Sign in → Select **Cluster0**
3. Click **Browse Collections**
4. Select database: **`adaptiq`**
5. Explore collections: `users`, `quizzes`, `quiz_results`, `learning_paths`, `modules`, `progress_records`

## Indexes

MongoDB auto-creates indexes for `@Id` fields. The following are recommended for production:

```js
// users collection
db.users.createIndex({ "email": 1 }, { unique: true })

// quizzes collection
db.quizzes.createIndex({ "userId": 1 })

// quiz_results collection
db.quiz_results.createIndex({ "userId": 1 })
db.quiz_results.createIndex({ "quizId": 1 })

// progress_records collection
db.progress_records.createIndex({ "userId": 1, "moduleId": 1 })
```
